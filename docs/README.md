# Splativerse website

Jekyll source for GitHub Pages. Publish `main` → `/docs` with GitHub's branch-based Pages build.

- Home: https://ncubeeight.github.io/Splativerse-for-visionOS/
- Privacy: https://ncubeeight.github.io/Splativerse-for-visionOS/privacy/

Local preview from the repository root with Jekyll installed:

    jekyll serve --source docs --destination /tmp/splativerse-site

The logo is the supplied Splativerse artwork. All fonts and assets are local;
no analytics, cookies, JavaScript, external fonts, or embedded viewers are added.

Validation: built locally with Jekyll 3.9.0; rendered home/privacy pages and
internal asset links checked. GitHub Pages performs the hosted build.
