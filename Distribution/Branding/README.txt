SPLATIVERSE LOGO

SplativerseLogo.jpg is an unchanged copy of the supplied original.
The app icon uses a 1024 x 1024 resampling of this artwork in the back
layer of the visionOS icon catalog. Upper layers are transparent because
the supplied artwork is flattened; the old placeholder artwork is removed.
visionOS applies its circular mask. AppIcon-preview.png shows that crop.

To regenerate from the repository root on macOS:
  swift Scripts/prepare-app-icon.swift

The original JPEG and preview are source/distribution resources. The app
bundles the compiled icon catalog. No generated replacement artwork is used.
